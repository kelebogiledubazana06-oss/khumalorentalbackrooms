# khumalorentalbackrooms
A responsive website for advertising and communicating with customers.

## Features
- **Responsive Layout**: Works beautifully on mobile phones, tablets, and desktop computers.
- **Service Advertising**: Showcases available backrooms, rental spaces, and pricing details.
- **Customer Communication**: Includes contact forms/links to make inquiries straightforward for users.

## 🛠️ Built With
- HTML
