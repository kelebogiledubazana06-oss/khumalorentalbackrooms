- **Customer Communication**: Includes contact forms/links to make inquiries straightforward for users.

## Sitemap

-  **Home** (`index.html`) - Introduction and overview of the residence.
-  **About Us** (`about.html`) - Details regarding the property management and core values.
-  **Backrooms** (`backrooms.html`) - Main directory of available properties with functional sorting and filter controls.
-  **Contact Us** (`contact.html`) - Custom client-side validated booking and enquiry form.
-  **Gallery** (`gallery.html`) - Visual display of accommodations and property amenities.

#### Added
- **Interactive Map:** Integrated a functional map element to dynamically show the physical location of the Khumalo Residence.

- Added the style to all the buttons and links

- **Typography Refresh:** Systematically edited and updated global font types across all style layers to establish a more premium and cohesive visual identity.
